6. INPUT PREPROCESSING
-----------------------
  Input lead:
    MIT-BIH: MLII (preferred), fallback to V5/V1
    INCART: Lead II (MLII-equivalent)
  Sampling frequency: 250 Hz (resampled from 360/257 Hz)
  Beat window: 0.8s before + 0.8s after R-peak = 1.6s
  Beat length: 400 samples (250 Hz x 1.6s)
  Normalization: Z-score (per-beat: subtract mean, divide by std)
  Tensor shape: (1, 400) -- single channel

7. MODEL ARCHITECTURE
-----------------------
  Model: ResNet1D_Beat (lightweight 1D residual network)
  Parameters: 246,741

  Architecture:
    Stem: Conv1d(1->16, k=15, s=2) + BN + ReLU + Dropout(0.15)
    Block1: ResBlock(16->32, k=7, s=2) + Dropout(0.3)
    Block2: ResBlock(32->64, k=7, s=2) + Dropout(0.3)
    Block3: ResBlock(64->128, k=7, s=2) + Dropout(0.3)
    GAP: AdaptiveAvgPool1d(1)
    FC: 128 -> 64 -> 5 classes + Dropout(0.3)

  Input shape: (B, 1, 400)
  Output shape: (B, 5) -- logits for N, S, V, F, Q
